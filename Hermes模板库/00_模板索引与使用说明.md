## 二、使用规则（Hermes 强制遵守）

1. **先读后写**：生成任何结构化文档前，先读取对应模板文件全文
2. **按节填写**：严格遵循模板章节结构，不自行增删一级章节
3. **可选即删**：模板中标注【可选】的章节，无内容时整节删除，不留空壳
4. **占位符清零**：交付文档中不得残留 `【】` 占位符和 `> 💡` 填写指引
5. **版本号制**：文档头必须带版本号；评审通过后升版并记录修改历史
6. **编号回溯**：所有文档间引用必须用编号（PRD#US-nn / HLD#M-n / DD#章节 / 任务卡#T-nnn），禁止仅写文件名

## 四、场景速查：遇到什么事，用哪个模板

| 场景 | 动作链 |
|------|--------|
| 接到新需求（Tier 2） | 澄清 → 填 01（建追踪矩阵）→ 用 05 开评审会（L2+） |
| 需求确认 | 填 02（设计条目逐条回溯 US 编号）→ 用 05 开技术评审会 |
| 设计确认 | 填 03（逐模块）→ 拆任务 |
| 拆任务 | 每个任务填一张 04（含 files_scope 与编号回溯） |
| 派任务 | 复制 04 第四节"派发通知"发给执行 Agent |
| 检查点到来 | 填 06（派发确认/里程碑/用户询问/阻塞时） |
| 出现分歧/变更 | 判级：L1 直接确认；L2 用 05 开会；L3 开会 + 用户终审 |
| 任务收尾 | 填 07（7 项验证 + 追踪矩阵核对）→ 更新 08 看板 |
| 每日收工 | 08 看板摘要报告 + 次日计划 |
