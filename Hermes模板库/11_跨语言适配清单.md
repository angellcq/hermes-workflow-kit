## 二、强类型编译型（Java / Go / Rust / Kotlin / C++ / C# / Swift）

### 2.1 通用规范

| 维度 | 规范 |
|------|------|
| **命名** | 驼峰/蛇形按语言约定；常量全大写下划线；类型/接口大写开头 |
| **类型** | 严格禁止隐式类型转换；nullable 类型显式标注；接口优于类继承 |
| **错误处理** | 不静默吞错；显式 error/Exception 向上抛；关键路径日志带上下文 |
| **并发** | 共享状态加锁或无状态化；避免全局可变；锁顺序统一防死锁 |
| **资源管理** | 自动释放（defer/RAII/using）；文件/连接必须关闭 |
| **模块边界** | 公共 API 最小化；内部实现不导出；接口冻结后禁止随意改签名 |

### 2.2 各语言要点

**Java（17+）**
- 使用 `record` 替代简单 DTO；`sealed class` 控制继承
- 集合操作优先 Stream API，但避免超过 3 层嵌套
- 依赖注入优先构造器注入；禁止字段注入
- 测试：JUnit 5 + Mockito + AssertJ；覆盖率用 JaCoCo 测量

**Go（1.21+）**
- `gofmt`/`goimports` 强制；`go vet`/`staticcheck` 通过
- 错误用 `errors.Is`/`errors.As` 断言；自定义错误实现 `Error() string`
- 并发：channel 优先；goroutine 数量可控；`context.Context` 贯穿调用链
- 测试：标准库 `testing` + `testify`；表驱动测试；覆盖率用 `go test -cover`

**Rust（2021 edition+）**
- `cargo fmt`/`cargo clippy` 强制；`unsafe` 必须有注释说明
- 错误用 `Result<T, E>`；`panic!` 仅用于不可恢复错误
- 所有权/借用检查通过；生命周期标注清晰
- 测试：标准 `#[test]` + `proptest`（属性测试）；覆盖率用 `cargo-llvm-cov`

**Kotlin（1.9+）**
- 空安全类型 `String?`/`String` 严格区分
- 协程：`CoroutineScope`/`launch`/`async`/`Flow`；禁止 `runBlocking` 在生产代码
- 数据类 `data class` 替代 Java Bean
- 测试：JUnit 5 + Kotest + MockK；覆盖率 Kover

**C++（C++17/20）**
- RAII 强制；智能指针 `unique_ptr`/`shared_ptr`；禁止裸 `new`/`delete`
- `auto` 适度使用；避免隐式转换
- 模板元编程需注释；SFINAE 复杂场景用 `concepts`（C++20）
- 测试：GoogleTest/GoogleMock + gcov/lcov

**C#（.NET 8+）**
- nullable reference types 启用；记录类型 `record`/`record struct`
- LINQ 适度；异步全链路 `async/await`；`CancellationToken` 贯穿
- 测试：xUnit + NSubstitute + FluentAssertions；覆盖率 coverlet

**Swift（5.9+）**
- SwiftUI 优先 UIKit（旧项目保留）；`async/await` 替代回调
- `Codable` 序列化；`@MainActor` 标注 UI 相关
- 测试：XCTest + Quick/Nimble；覆盖率 Xcode 内置

## 三、动态解释型（Python / JavaScript / Ruby / PHP / Lua）

### 3.1 通用规范

| 维度 | 规范 |
|------|------|
| **类型** | 启用类型注解（Python typing / TypeScript / Ruby Sorbet / PHP Psalm） |
| **风格** | Linter 强制（pylint/eslint/rubocop/phpcs） |
| **依赖** | requirements.txt + lock 文件（pip-tools / npm ci / bundler） |
| **并发** | 异步优先（asyncio / Promise / Fiber / Swoole） |
| **错误** | 异常向上抛；自定义异常类；不要用裸 except/try-catch 吞错 |
| **可测试** | 单元 + 集成 + E2E 三层；覆盖率 ≥80% |

### 3.2 各语言要点

**Python（3.11+）**
- 类型注解：`from typing import ...`；复杂结构用 `TypedDict`/`dataclass`/`Pydantic`
- Linter：ruff（替代 flake8+isort+black）；格式化 ruff format
- 异步：asyncio + httpx；避免阻塞调用混用
- 包管理：uv / poetry；lock 文件入库
- 测试：pytest + pytest-cov + hypothesis（属性测试）

**JavaScript / TypeScript**
- TypeScript strict 模式；`any` 禁止（除非明确边界）
- ESLint + Prettier 强制；ESM 模块优先
- 测试：Vitest/Jest + Testing Library；覆盖率 c8/v8
- 依赖：npm ci / pnpm install --frozen-lockfile

**Ruby（3.2+）**
- 风格：rubocop 强制；类型：Sorbet / RBS
- 测试：RSpec + SimpleCov
- 依赖：Bundler；lock 文件入库

**PHP（8.2+）**
- 类型：标量/返回类型/属性类型；`declare(strict_types=1);`
- 风格：php-cs-fixer / phpcs
- 测试：PHPUnit + Pest
- 框架：Laravel/Symfony 用对应测试栈

## 四、脚本型（Bash / PowerShell / Makefile / Batch）

### 4.1 通用规范（安全第一）

| 维度 | 规范 |
|------|------|
| **入口** | `set -euo pipefail`（Bash）；`$ErrorActionPreference = "Stop"`（PowerShell） |
| **参数校验** | 必填参数缺失即报错退出；不允许 silent failure |
| **路径** | 禁止 `rm -rf $UNCHECKED_VAR`；路径白名单或相对项目根 |
| **错误处理** | trap + EXIT handler 清理临时文件；显式错误码退出 |
| **可移植性** | 避免 Bash 专属语法（如 `[[ ]]`）除非显式要求 Bash；跨平台用 shebang 标注 |

### 4.2 各脚本要点

**Bash（4.0+）**
- 用 `shellcheck` 通过；长脚本拆函数
- 引号：变量必须双引号包裹；避免 word splitting
- 测试：bats-core（bash自动化测试系统）

**PowerShell（7+）**
- 跨平台用 PowerShell Core（`pwsh`）；避免 Windows PowerShell 5.1 专属语法
- 风格：PSScriptAnalyzer 通过
- 测试：Pester

**Makefile**
- `.PHONY` 声明伪目标；`$@`/`$<`/`$^` 显式使用
- 默认目标 `all`；每个 target 单一职责

## 五、前端框架（Vue / React / Svelte / 微信小程序）

### 5.1 通用规范

| 维度 | 规范 |
|------|------|
| **组件** | 单一职责；props 强类型（TS）；事件向上抛 |
| **状态管理** | 小应用：组件 state；中应用：Pinia/Vuex/Zustand/Redux；跨页：URL/query |
| **样式** | scoped CSS / CSS Modules / Tailwind / UnoCSS；禁止全局污染 |
| **路由** | 路由懒加载；权限路由 meta 声明 |
| **国际化** | i18n key 集中管理；硬编码中文/英文禁止 |
| **可访问性** | a11y 基础：aria-label、语义化标签、键盘可达 |
| **兼容性** | 浏览器最低版本声明；polyfill 按需 |

### 5.2 各框架要点

**Vue 3**
- Composition API + `<script setup lang="ts">`；优先 ref/reactive 而非 mixin
- 风格：ESLint + Prettier；Vue 官方风格指南
- 测试：Vitest + Vue Test Utils

**React 18+**
- 函数组件 + Hooks；禁止 class component
- 状态：服务器状态 React Query；客户端状态 Zustand/Redux Toolkit
- 测试：Vitest + React Testing Library + MSW（API mock）

**Svelte / SvelteKit**
- `.svelte` 单文件组件；stores 跨组件共享
- 测试：Vitest + @testing-library/svelte

**微信小程序**
- 双线程模型（逻辑层/渲染层）；setData 最小化
- 组件化：自定义组件 + behaviors
- 测试：miniprogram-automator + jest

## 六、移动端（iOS / Android / Flutter / React Native）

### 6.1 iOS（Swift / SwiftUI）

- SwiftUI 优先；UIKit 旧项目保留
- 内存：避免循环引用；weak/unowned 标注
- 线程：MainActor 标注 UI；后台队列明确
- 性能：Instruments 检测；启动时间 < 400ms

### 6.2 Android（Kotlin / Jetpack Compose）

- Jetpack Compose 优先；XML 旧项目保留
- 协程全链路；Room 数据库；Hilt 注入
- 性能：LeakCanary + Macrobenchmark

### 6.3 Flutter（Dart）

- null safety 启用；Riverpod/Bloc 状态管理
- 测试：flutter test + integration_test

### 6.4 React Native

- TypeScript 强制；Hermes 引擎
- 导航：React Navigation；状态：Zustand/Redux Toolkit
- 原生模块：Turbo Modules（新项目）/ 旧项目 Native Modules

## 七、数据/ML（SQL / Python 数据栈 / R）

### 7.1 SQL（跨方言通用）

- **关键字大写**：`SELECT`/`FROM`/`WHERE`；表/字段小写蛇形
- **命名**：表名复数；主键 `id`；外键 `<ref_table>_id`；时间字段 `_at`/`_date`
- **索引**：高频查询列；外键；时间字段
- **NULL**：明确 `IS NULL` / `IS NOT NULL`；不要用 `= NULL`
- **事务**：DML 必须显式事务；大事务拆小
- **可移植性**：避免方言专属语法；CTE 优先于子查询

### 7.2 Python 数据栈

- numpy/pandas 优先；避免 Python 循环处理大数据
- 模型可复现：random seed；超参记录（MLflow/W&B）
- 数据版本化：DVC / Delta Lake

### 7.3 R

- tidyverse 风格；脚本化分析
- shiny 应用分模块

## 八、混合栈

当项目涉及多种语言/栈时：

1. **明确边界**：每个模块的栈边界清楚，跨边界通过 HTTP/gRPC/Message Queue
2. **接口契约**：跨语言接口用 OpenAPI/Protobuf/GraphQL 定义；前后端共享类型生成
3. **双技能加载**：编码 Agent 同时加载多个语言的 cross-language 子规范
4. **统一测试**：跨边界用契约测试（Pact / WireMock）
5. **覆盖率取最高**：各栈的测试门槛取最高（如：后端 ≥80% + 前端 ≥70%）
