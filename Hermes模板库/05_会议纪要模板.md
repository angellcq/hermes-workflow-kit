# 会议纪要模板（合并版）
> **模板编号**: 05 ｜ **环节**: 多 Agent 协商会议（召集 → 讨论 → 决议 → 行动项跟踪）
> **填写人**: Hermes（会议发起人兼记录人）
> **前置判级**: L1 单文档小歧义不开会（列选项向用户确认一次即可）；L2 跨文档不一致/模块冲突/架构分歧开会；L3 不可逆操作/需求方冲突开会且必须用户终审
> **用法**: 会前填第一、二节并发出召集；会中填三、四、五节；会后 24 小时内补齐六、七节并同步看板
> **命名**: `会议纪要_YYYYMMDD_主题.md`

## 三、问题陈述（Hermes 开场，≤200 字）

【说清楚三件事：要决策什么、为什么现在必须决策、有哪些可选方向。不夹带倾向性结论。】

## 四、各方观点

> 💡 每个 Agent 限时 1 轮发言；只记录观点+依据，不做评价；逐方记录，禁止转述合并

| 发言方 | 观点 | 依据（数据/事实/经验） | 倾向方案 |
|--------|------|------------------------|----------|
| 【需求方代表】 | 【观点】 | 【依据】 | 【方案 A】 |
| 【架构师】 | 【观点】 | 【依据】 | 【方案 B】 |
| 【开发执行代表】 | 【观点】 | 【依据】 | 【方案 X】 |
| 【质量守门员】 | 【观点】 | 【依据】 | 【方案 X】 |

## 五、分歧点汇总

【列出主要分歧，明确冲突实质。若各方观点一致，写"无明显分歧"。】

1. 【分歧点 1】:【A 方认为……，B 方认为……，冲突实质是……】
2. 【分歧点 2】:……

## 六、会议决议

| 字段 | 内容 |
|------|------|
| 决议方式 | 【共识达成 / Hermes 最终决策】 |
| 决议内容 | 【最终决策，一句话可执行】 |
| 决策依据 | 【为什么这么定：数据、约束、成本对比】 |
| 反对意见 | 【如有，原样记录以供回溯；无则写"无"】 |
| 回写文档 | 【决议回写至 PRD/HLD/DD 的编号 + 版本升级 vX.Y→vX.Y+1】 |
| 生效条件 | 【立即生效 / 待用户终审后生效（L3）】 |

> 💡 决议执行规则：决议一旦形成所有 Agent 必须执行；推翻决议必须提供新的事实依据并重新召集会议；本纪要持久化存储，支持事后审计。
