# 移交文档模板（HANDOFF · 跨 Agent 交接契约）

> **模板编号**: 09 ｜ **环节**: 跨 Agent 任务交接 ｜ **填写人**: 前序 Agent
> **用法**: 任务跨 Agent 移交时（如：plan → dev → review → test），由前序 Agent 填写本模板落盘到 worktree 根目录的 `HANDOFF_<任务ID>.md`，后续 Agent 只读此文档 + 任务卡 + 引用文件，不依赖聊天记录
> **硬规则**: 前序 Agent 必须填写完整才允许进入下一环节；后续 Agent 必须读完才允许动手

---

## 4. 汇报要求（三态）

完成后必须以三态之一汇报：

1. **完成**：附证据（测试结果 / 产出物路径 / diff 摘要）
2. **阻塞**：附原因与已尝试的办法
3. **偏差**：附影响范围与建议方案
